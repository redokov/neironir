### Задача A — спека 008: убрать токен из адреса ссылки (идея 005)

Идея: `.ai/sdd/ideas/005-remove-access-token-query-fallback.md`.
Проблема: браузерное скачивание идёт по ссылке `<a href>` с токеном в
параметре адреса `?access_token=...` — токен оседает в истории браузера,
журналах сервера и заголовке перехода.

**Фаза 1 — SDD-артефакты** (пиши сам, это документы, не правка кода):
создай `.ai/sdd/specs/008-remove-access-token-query-fallback/`:
- `requirements.md` (скил sdd-prd): требование — токен задачи не появляется
  в URL нигде и никогда; скачивание из веб-интерфейса — запросом из сценария
  с заголовком `X-Job-Token`; запасная ветка `?access_token=` на сервере
  удаляется. Зафиксируй ломающее изменение: старые открытые ссылки со
  встроенным токеном перестают работать (приемлемо, версия до 1.0).
- `design.md` (скил sdd-spec): факты для проекта уже собраны —
  сервер: `backend/neironir/api/jobs.py`, функция `verify_job_access`,
  ветка `request.query_params.get("access_token")` — удалить, оставить
  только заголовок `X-Job-Token` (+ docstring);
  фронтенд: `frontend/app.js` (проверь и `frontend/admin.js`) — скачивание
  переделать на `fetch` с заголовком + `Blob`/`URL.createObjectURL` для
  сохранения файла; токен уже хранится в состоянии фронтенда после 007;
  тесты: найди проверки параметра `access_token` в `tests/` (grep) —
  позитивные убрать, оставить негативную «параметр не работает → 404»;
  документация: `docs/api.md`, раздел «Job access token» — абзац про
  query-параметр заменить описанием скачивания через сценарий; CHANGELOG —
  новый раздел `[Unreleased]` с пометкой «Изменено (ломающее)».
- `tasks.md` (скил sdd-tasks): задачи T1…Tn с чек-листами, файлами,
