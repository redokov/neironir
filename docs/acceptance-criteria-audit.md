### Что в статусе «нет»

1. **uv не в PATH** — установлен и используется через `.venv`, но `uv --version` в bash не работает. Не влияет на функциональность.
2. **make не в PATH** — целевой make-файл есть, но на Windows make отсутствует. Все команды доступны через `uv run …`. Не влияет.
3. **Чекпойнт opf не скачан** — не удалось докачать 2.8 ГБ модели. Без этого subprocess-режим неработоспособен.
4. **Subprocess e2e (4 пункта)** — не проверены, так как нет чекпойнта.
5. **CI не запущен** — GitHub Actions workflow написан, но не было push в удалённый репозиторий. 3 производных пункта (запуск workflow, 3.11, artifact) не подтверждены.
