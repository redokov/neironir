# Idea 005: Remove `?access_token=` query fallback

**Проблема.** Браузерное скачивание идёт по ссылке `<a href>` с токеном в
query-параметре `?access_token=...` — job-токен попадает в URL, историю
браузера, access-логи и referrer. Digest-only модель (spec 007 T3) защищает
хранилище, но сам токен всё равно протекает на транспортном уровне.

**Предложение.** Перейти во фронтенде на скачивание через `fetch()` с
заголовком `X-Job-Token` (и `Blob`/`URL.createObjectURL` для сохранения
файла); убрать query-фолбэк из `/download` на сервере. Опционально —
короткоживущий одноразовый download-ticket, если navigation-скачивание
всё же нужно.

**Оценка усилия.** S: фронтенд ~30 строк + удаление ветки query-параметра
в `jobs.py` + обновление затронутых тестов. Обратная совместимость ломается
только для старых ссылок с токеном в URL — приемлемо для pre-1.0.
