# Changelog

Все значимые изменения проекта документируются в этом файле.

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
версионирование — [Semantic Versioning](https://semver.org/lang/ru/).

## [0.1.0] — 2025-07-16

Первый тегированный релиз: стабилизация после Фазы 2 по результатам
углублённого код-ревью (см. `code-review-report.md`).

### Исправлено

- **Админка: порядок документов с фидбеком.** Список
  `GET /api/v1/admin/documents` сортировался по имени каталога (UUID), а не
  по дате, и `limit` отрезал произвольное подмножество. Теперь записи
  сортируются по `finished_at` (с fallback на `created_at`) по убыванию,
  лимит применяется после сортировки — сверху всегда самые свежие правки.
- **Runtime-таймаут OPF применяется без рестарта.** `PUT /api/v1/admin/settings`
  раньше писал значение в файл и в мёртвый атрибут настроек, а живой клиент
  продолжал работать со старым таймаутом до перезапуска. Теперь эндпоинт
  обновляет синглтон privacy-клиента на лету (`update_privacy_timeout`);
  тот же override учитывается и при запуске дообучения.
- **Open redirect в `GET /login`.** Параметр `?next=` не проверялся для
  уже аутентифицированного пользователя. Общий `_safe_next_url()` теперь
  отсекает абсолютные URL, protocol-relative (`//host`) и backslash-трюки
  в обоих обработчиках логина.
- **Валидация ручных правил.** `POST /api/v1/rules` возвращает 422 на
  неизвестный `entity_type`, и добавленное вручную правило сразу
  hot-reload'ится в детектор (как при approve).
- **Целостность файлов.** `counters.json` при apply-feedback пишется
  атомарно; битый `job.json` в деталях документа отдаёт корректный
  500-конверт вместо traceback.

### Изменено

- Токенизация `privacy_filter_cmd` унифицирована в
  `neironir.config.parse_opf_cmd()` (shlex, защита Windows-путей и
  кавычек) и используется и в annotation-, и в training-путях.

### Тесты

- +30 новых тестов: сортировка/лимит документов, `parse_opf_cmd`,
  `update_privacy_timeout`, runtime-settings API, open-redirect кейсы,
  API ручных правил. Общее покрытие — 85% (гейт CI: 70%).

## [0.0.1] — MVP

- Базовый пайплайн: загрузка `.md`/`.docx` → извлечение текста →
  privacy-filter (mock/subprocess/combined) → превью → скачивание.
- Админка: статистика, документы с фидбеком, правила, дообучение.
- Аутентификация (сессия + CSRF), атомарные записи хранилища,
  fallback с subprocess на mock.
